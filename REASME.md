# Cricket Player Sentiment Analysis

## Project Description
This project analyzes social media comments about cricket players and identifies whether the comments are Positive, Negative, or Neutral.

## Players
- Virat Kohli
- Rohit Sharma
- Jasprit Bumrah

## Technologies Used
- Python
- Pandas
- NumPy
- TextBlob
- Matplotlib

## Dataset
The dataset contains cricket player names and comments.

## Output
The project shows:
- Sentiment of each comment
- Total positive comments
- Total negative comments
- Total neutral comments
- Player-wise sentiment analysis
- Graphs for visualization

## Result
The sentiment analysis is successfully completed using Python.
