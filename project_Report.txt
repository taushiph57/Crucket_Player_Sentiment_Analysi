1. INTRODUCTION

Cricket is one of the most popular sports, and many people share their opinions about cricket players on social media. These comments can be positive, negative, or neutral.

Cricket Player Sentiment Analysis is a project that analyzes comments about cricket players and identifies their sentiment. In this project, Python and TextBlob are used to analyze the comments.

The project analyzes comments related to Virat Kohli, Rohit Sharma, and Jasprit Bumrah. The results are stored in a CSV file and represented using graphs for easy understanding.

2. OBJECTIVES

The main objectives of this project are:

1. To analyze comments related to cricket players.
2. To identify whether a comment is Positive, Negative, or Neutral.
3. To calculate the total number of positive, negative, and neutral comments.
4. To perform player-wise sentiment analysis.
5. To display the analysis results using graphs.
6. To understand how Python can be used for sentiment analysis.

- Jasprit Bumrah

Each comment is analyzed and classified as Positive, Negative, or Neutral.

5. METHODOLOGY

The project works in the following steps:

Step 1: Dataset Collection
Cricket player comments are collected and stored in a CSV file.

Step 2: Data Loading
The Python program uses Pandas to read the CSV dataset.

Step 3: Sentiment Analysis
TextBlob analyzes each comment and calculates its sentiment polarity.

Step 4: Sentiment Classification
Based on the polarity value, each comment is classified as:
- Positive
- Negative
- Neutral

Step 5: Result Storage
The analyzed results are saved in a CSV file named sentiment_results.csv.

Step 6: Visualization
Matplotlib is used to create graphs showing the sentiment results.

Step 7: Project Summary
The program displays the total number of comments and the number of Positive, Negative, and Neutral comments.

6. IMPLEMENTATION

The project is implemented using Python in Visual Studio Code.

First, the cricket comments are loaded from the CSV file using Pandas. Then TextBlob is used to analyze the sentiment of each comment.

The sentiment polarity is checked for every comment:

- If polarity is greater than 0 → Positive
- If polarity is less than 0 → Negative
- If polarity is equal to 0 → Neutral

After analysis, the results are saved in the output folder as sentiment_results.csv.

Matplotlib is also used to create graphs for visualizing the sentiment results.
